# Gear to compare

Match the radio to the hub you already own before you add another brand.

- **Wi-Fi** devices talk to your router. Many of them need the vendor cloud.
- **Zigbee and Z-Wave** devices need a hub or a Home Assistant radio.
- **Thread / Matter** devices need a border router. A phone that "supports Matter" is not always that router.
